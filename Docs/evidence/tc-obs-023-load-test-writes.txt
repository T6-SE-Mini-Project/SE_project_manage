Diagnosis of the 490 failed add_to_cart requests
------------------------------------------------
Reproduced with DJANGO_DEBUG=true and 20 concurrent POST /api/cart/items/
requests: 16 of 20 returned HTTP 500 with

    OperationalError at /api/cart/items/
    database is locked

SQLite permits a single writer at a time, so concurrent cart writes
serialise and then time out. This is a limitation of the test substrate,
not of the application: the project baseline is MySQL 8.0, which uses
row-level locking. The write path at 500 concurrent users is therefore
NOT validated by this run and must be re-measured against MySQL.
